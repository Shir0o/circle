# Contributing to Circle

Thank you for your interest in contributing to **Circle**! We welcome bug reports, feature suggestions, and code contributions.

## How to Contribute

1. **Fork & Clone**: Fork the repository on GitHub and clone it locally.
2. **Branching**: Create a feature branch off of `main`:
   ```bash
   git checkout -b feature/my-new-feature
   ```
3. **Coding Standards**:
   - Follow standard Dart and Flutter formatting (`dart format .`).
   - Ensure `flutter analyze` reports zero errors or warnings.
   - Include unit or widget tests for all new features.
4. **Testing**:
   Run tests before submitting your pull request:
   ```bash
   flutter test
   ```
5. **Submit Pull Request**: Push your branch to GitHub and open a Pull Request targeting `main`.

## Code of Conduct

Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all project interactions.
